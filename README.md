## About Repository

This repository contains the lecture materials, notebooks, code, datasets, assignments, demonstrations, and resources used during the Industry-Oriented AI Training Program conducted from **August 17 2026**.

The objective of this training is to help students build a practical understanding of Artificial Intelligence, starting from fundamental Machine Learning (Linear and Logistic Regression of Regression and Classification tasks) concepts and gradually moving toward Introduction to Generative AI, LLM concepts and Prompt Engineering, Microsoft Copilot, Responsible AI, and AI-powered automation.

---

🎯 Training Objectives

By the end of the program, students should be able to:

- Understand the difference between AI, ML, DL, and Generative AI
- Understand the AI Project Cycle and ML development lifecycle
- Identify different types of Machine Learning problems
- Build and evaluate Regression models
- Build and evaluate Classification models
- Understand the mathematical intuition behind:
- Linear Regression
- Logistic Regression
- Gradient Descent
- Sigmoid Function
- Binary Cross Entropy
- Develop complete ML projects using real-world datasets
- Understand how Language Models (LMs), LLMs, and Transformers are related
- Use pre-trained Transformer models through Hugging Face
- Apply practical Prompt Engineering techniques
- Build simple AI-powered research systems
- Understand AI bias, hallucinations, privacy, security, and other AI risks
- Understand the fundamentals of the EU AI Act and GDPR
- Understand AI-powered automation and workflow systems
- Explore n8n and AI automation
- Develop awareness of the future of Agentic AI
