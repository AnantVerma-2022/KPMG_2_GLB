## About Repository

This repository contains the lecture materials, notebooks, code, datasets, assignments, demonstrations, and resources used during the Industry-Oriented AI Training Program conducted from **August 17 2026**.

The objective of this training is to help students build a practical understanding of Artificial Intelligence, starting from fundamental Machine Learning (Linear and Logistic Regression of Regression and Classification tasks) concepts and gradually moving toward Introduction to Generative AI,LLM concepts and Prompt Engineering, Microsoft Copilo, Responsible AI, and AI-powered automation.
